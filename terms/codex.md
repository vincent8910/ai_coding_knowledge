# Codex — OpenAI 的 AI 程式助手平台，ChatGPT 的「動手做事」版本

> **白話說：** 如果 ChatGPT 是「出一張嘴的顧問」，Codex 就是 ChatGPT 的**實習生升正職**——以前只會聊天給建議，現在能幫你寫程式、改檔案、跑測試。

---

## 它到底是什麼？

你知道 Claude Code 是 Anthropic 推出的「AI 程式助手」嗎？

**Codex 就是 OpenAI（ChatGPT 的公司）推出的類似產品。**

就像可口可樂 vs 百事可樂、iPhone vs Android——同一個市場，不同公司的產品。

| | Claude Code（Anthropic） | Codex（OpenAI） |
|---|---|---|
| 定位 | AI 程式助手 | AI 程式助手 |
| 使用方式 | [終端機](terminal-cli.md)（CLI） | 桌面應用程式 + CLI（codex-cli） |
| 支援系統 | macOS + Windows | macOS + Windows |
| 訂閱方案 | Claude Pro / Max | ChatGPT Plus / Pro |
| 特色功能 | Subagent 分身術、MCP 外接工具 | 多 Agent 並行、雲端沙盒 |

## 跟 ChatGPT 有什麼不同？

| | ChatGPT（聊天） | Codex（動手做事） |
|---|---|---|
| 你說 | 「怎麼修這個 bug？」 | 「幫我修好這個 bug」 |
| AI 做 | 告訴你修法，你自己動手 | 直接改好程式碼，跑測試確認沒問題 |
| 像什麼 | 問路的路人 | 幫你開車的司機 |
| 能操作檔案嗎 | ❌ 不行 | ✅ 可以讀寫你的專案檔案 |

## Codex 的特色

1. **桌面應用程式**：不只有指令介面，還有視覺化的桌面 App，對新手比較友善
2. **多 Agent 並行**：可以同時派出多個 AI 處理不同任務（跟 Claude Code 的 Subagent 概念類似）
3. **雲端沙盒**：AI 在雲端的安全環境裡執行，不會直接動到你的電腦（更安全但也更慢）

## 我該選 Claude Code 還是 Codex？

這就像問「我該用 iPhone 還是 Android？」——沒有絕對的答案，看你的需求：

| 你的情況 | 建議 |
|---------|------|
| 已經在用 ChatGPT Plus | 可以先試 Codex，不用額外付費 |
| 已經在用 Claude Pro / Max | Claude Code 跟你的方案整合更好 |
| 想要最強的程式能力 | 兩個都試試，看哪個適合你 |
| 完全的新手 | Codex 的桌面 App 可能比較好上手 |

> 💡 市場上還有 [Google Antigravity](antigravity.md)（Google 的版本）。三大 AI 公司都推出了自己的程式助手，競爭很激烈，功能也在快速進步。
