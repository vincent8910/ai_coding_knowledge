# Computer Use（電腦操控）— AI 不只出嘴巴，還能直接幫你操作電腦

> **白話說：** 以前的 AI 只能用嘴巴回答你的問題，現在它能**拿起滑鼠、看著螢幕、幫你點按鈕**——就像一個遙控員工，真的坐在你電腦前幫你操作。

---

## 它到底是什麼？

想像你請了一個超聰明的顧問，但他只會「說」不會「做」。你問他怎麼設定 Excel 報表，他會一步步告訴你，但你還是得自己動手。

**Computer Use 就是讓這個顧問變成遙控員工。**

他現在能：
- 👀 **看到**你的螢幕畫面
- 🖱️ **點擊**按鈕、選單、連結
- ⌨️ **打字**填寫表單
- 📂 **開啟**應用程式和檔案

簡單說：AI 從「出一張嘴的顧問」升級成「動手幫你做事的員工」。

## 生活比喻

| 情境 | 以前的 AI | 有 Computer Use 的 AI |
|------|----------|---------------------|
| 你要填報名表 | 告訴你「先點這裡、再填那裡」 | 直接幫你打開網頁、填好表格、按送出 |
| 你要整理桌面 | 告訴你「把這些檔案分類到資料夾」 | 直接幫你拖拉檔案、建資料夾、分類好 |
| 你要改簡報 | 告訴你怎麼改字型和排版 | 直接打開 PowerPoint、改好字型、調好排版 |

**就像遠端桌面，但操作你電腦的不是另一個人，而是 AI。**

## 哪裡可以用？

目前支援 Computer Use 的服務：

| 平台 | 支援狀態 | 備註 |
|------|---------|------|
| Claude（Pro / Max 方案） | ✅ 已推出 | Anthropic 自家的 Computer Use 功能 |
| OpenAI Operator | ✅ 已推出 | ChatGPT 的類似功能，主要針對網頁操作 |
| Windows + macOS | ✅ 都支援 | 跨平台操作 |

## 為什麼非技術人員應該關注？

這可能是**對非技術人員最有感的 AI 功能**。

以前要用 AI 做事，你得會打指令、懂程式。但 Computer Use 不一樣——它操作的就是你平常用的那個畫面。你不需要學任何新東西，只要告訴 AI「幫我做什麼」，然後看著它幫你操作就好。

> ⚠️ **小提醒**：讓 AI 操作你的電腦時，建議先從簡單任務開始，確認它做對了再給它更大的任務。就像新員工剛到職，你也會先給小事讓他練手。
