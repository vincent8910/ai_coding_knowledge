# Plugin（外掛套件）— Skill 的進化版，一整包打包好的 AI 擴充功能

> **白話說：** 如果 [Skill](skill.md) 是手機裡的「快捷指令」，Plugin 就是一整個 **App**——裡面包含了所有需要的東西，下載就能用。

---

## 它到底是什麼？

你知道手機上的 App 跟快捷指令（捷徑）的差別嗎？

- **快捷指令**：一個小小的自動化動作，例如「長按電源鍵 → 自動打開手電筒」
- **App**：一整包功能，有畫面、有資料庫、有設定，例如整個「LINE」應用程式

**Plugin 就是 AI 世界裡的 App。**

它把 [Skill](skill.md)（指令）、設定檔、甚至 [MCP 伺服器](mcp.md)（外接工具）打包在一起，變成一個完整的功能包。

## Skill vs Plugin 差在哪？

| | Skill（快捷指令） | Plugin（App） |
|---|---|---|
| 包含什麼 | 一個 SKILL.md 指令檔 | Skill + 設定檔 + MCP 伺服器 + 其他資源 |
| 複雜度 | 簡單，一個檔案搞定 | 完整，像一個小型專案 |
| 安裝方式 | 複製一個檔案 | 從 GitHub 下載一整包 |
| 分享方式 | 傳一個檔案給同事 | 分享一個連結，對方一鍵安裝 |
| 能做的事 | 單一任務的自動化 | 複雜功能，可能包含多個任務 |
| 比喻 | iPhone 的「捷徑」 | iPhone 的「App」 |

## 舉個實際的例子

假設你要一個「自動分析股票」的功能：

**如果只用 Skill：**
- 一個 SKILL.md 檔案，寫著「怎麼分析股票」的步驟
- AI 按照步驟執行，但你要自己準備好資料來源

**如果用 Plugin：**
- Skill 指令：告訴 AI 怎麼分析
- MCP 伺服器：自動連線到股票資料網站抓數據
- 設定檔：你的偏好設定（追蹤哪些股票、分析頻率）
- 範本檔案：分析報告的格式模板

**一包搞定，下載就能直接用。**

## 我可以在哪裡用 Plugin？

Plugin 主要用在 Claude Code 裡：

1. 從 GitHub 找到你要的 Plugin
2. 用指令安裝（通常一行指令就搞定）
3. 安裝完就能直接使用

> 💡 Plugin 是比較進階的功能。如果你剛開始用 AI，先從 [Skill](skill.md) 開始就好，等熟悉之後再來看 Plugin。
