# Hooks（事件鉤子）— 讓 AI 在特定時機自動執行你預設的動作

> **白話說：** Hooks 就像門口的**感應燈**——有人走過就自動亮，不用你去按開關。你可以預設「AI 做完某件事之後，自動幫我做另一件事」。

---

## 它到底是什麼？

你有沒有用過這些東西？

- 🚪 門口的**感應燈**：有人經過 → 自動亮燈
- 🔔 門鈴的**對講機**：有人按門鈴 → 自動錄影
- 📱 手機的**自動化捷徑**：到家 → 自動開冷氣

**Hooks 就是 AI 版的「自動觸發器」。**

你可以設定：「當 AI 做了 X 這件事，就自動接著做 Y。」

## 生活比喻

| 觸發時機 | 生活中的例子 | AI 的例子 |
|---------|------------|----------|
| **做事之前** | 出門前自動檢查瓦斯 | AI 執行指令前，自動備份檔案 |
| **做事之後** | 洗完衣服自動烘乾 | AI 改完程式碼後，自動整理格式 |
| **出錯的時候** | 煙霧偵測器偵測到煙 → 自動灑水 | AI 執行失敗時，自動通知你 |

## 常見的 Hooks 用途

在 Claude Code 裡，你可以設定這些自動觸發器：

| Hook | 白話說明 | 像什麼 |
|------|---------|--------|
| 編輯檔案後自動格式化 | AI 改完程式碼，自動排版整齊 | 寫完作文，自動修正標點符號 |
| 執行指令前先確認 | AI 要跑危險指令前，先問你一聲 | 員工要花大錢前先給主管簽核 |
| 儲存前自動檢查 | 儲存檔案前先檢查有沒有錯誤 | 寄信前自動跑拼字檢查 |

## Hooks 設定在哪裡？

Hooks 是在 Claude Code 的 **settings.json**（設定檔）裡配置的。

你不需要自己去寫程式碼——通常是：
1. 團隊裡懂技術的人幫你設定好
2. 或是跟著教學一步步貼上設定

設定好之後就是**全自動**的，你完全不用管它，它會默默在背景幫你做事。

> 💡 **小提醒**：Hooks 是 Claude Code 的功能。如果你是用網頁版的 Claude，目前還用不到這個功能。
