# Subagent（子代理）— AI 的分身術，同時派出多個分身處理不同任務

> **白話說：** 一個 AI 忙不過來？沒關係，它可以**分身**——派出好幾個分身同時做不同的事，做完再回來匯報，就像主管派小隊成員分頭行動。

---

## 它到底是什麼？

想像你是一個專案主管，手上有一個大案子要趕：

- 需要有人去**蒐集市場資料**
- 需要有人去**寫企劃書**
- 需要有人去**做財務報表**

如果只有你一個人，你得一件一件做，超慢。但如果你能**派出三個分身**，三件事同時進行，速度就快三倍。

**Subagent 就是 AI 的分身術。**

主 AI（[Agent](agent.md)）可以派出多個 Subagent，每個分身負責不同的任務，同時進行，最後把結果彙整回來。

## 生活比喻

```
👔 主管（主 Agent = Claude Code）
│
├── 🔍 分身 A（Subagent）→ 去搜尋相關資料
│
├── 📝 分身 B（Subagent）→ 去寫程式碼
│
└── 🧪 分身 C（Subagent）→ 去測試功能
│
👔 主管彙整三個分身的結果 → 交給你
```

就像一個餐廳的主廚：
- 不是自己切菜、煮湯、烤肉全部來
- 而是指揮三個助手**分頭做**，最後自己組合出一道菜

## 每個 Subagent 有什麼特別？

| 特性 | 說明 | 比喻 |
|------|------|------|
| **獨立範圍** | 每個分身有自己的工作空間，不會互相干擾 | 每個員工有自己的辦公桌 |
| **專屬權限** | 每個分身只能做被授權的事 | 實習生不能簽合約 |
| **專屬工具** | 每個分身可以使用不同的工具 | 會計用 Excel、設計用 Figma |
| **自動回報** | 做完會自動把結果交回給主 Agent | 員工做完會跟主管報告 |

## 什麼時候會用到 Subagent？

| 場景 | 主 Agent 做什麼 | Subagent 做什麼 |
|------|----------------|----------------|
| 改很多檔案 | 規劃要改哪些東西 | 每個分身負責改不同的檔案 |
| 研究 + 執行 | 統籌整個流程 | 一個分身去查資料，一個分身去寫程式 |
| 大型重構 | 制定整體計畫 | 多個分身同時修改不同模組 |

## 我需要自己操作 Subagent 嗎？

**不用！** 這是 Claude Code 自動幫你做的事。

你只需要下一個指令，例如：「幫我把這個專案的所有頁面翻譯成英文」，Claude Code 會自己判斷需不需要派出分身，自己安排誰做什麼。

你要做的就是——**等結果就好**。

> 💡 Subagent 是 Claude Code 的進階功能。對於初學者來說，你不需要特別去學它，只要知道「AI 可以同時做很多事」就夠了。
